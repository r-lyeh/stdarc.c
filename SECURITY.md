# Security Policy

## Reporting a Vulnerability

This project does not currently have a dedicated security contact or
private vulnerability reporting enabled on GitHub.

If you believe you've found a security vulnerability in this project,
please:

1. **Do not open a public issue with technical details.**
2. Open a minimal issue titled "Security contact request" asking the
   maintainer to enable [GitHub Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
   on this repository, or to provide an alternate private contact
   method (e.g. email).
3. Once a private channel is available, please include: affected
   file(s)/function(s), a proof-of-concept, and an impact assessment.

We aim to acknowledge reports within a reasonable timeframe and will
credit reporters in any resulting security advisory, unless anonymity
is requested.
